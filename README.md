# nerd-pos

Public POS and business workflow prototype focused on cashier flows, reporting, and Arabic-first interfaces.

This repository is a public-facing POS sandbox used to explore how practical business software should behave at the point of sale. It focuses on day-to-day operational flows rather than marketing pages or generic UI demos.

## Focus areas

- Cashier and checkout workflows
- Product and pricing flows
- Order handling and operational controls
- Reporting and admin views
- Arabic-first UI and RTL support
- React and TypeScript frontend paired with backend business logic

## Public note

Some production business systems remain private for IP reasons. This repository is part of the public layer: prototypes, experiments, and implementation directions that show how I approach POS and operational software without exposing private deployments.

## Repository structure

- `frontend/` - UI work for POS and admin flows
- `backend/` - business logic and API-side work
- `PHASE1_VERIFICATION.md` and `PHASE2_VERIFICATION.md` - delivery and verification notes

## Status

This is a public prototype and engineering sandbox. It is useful as a showcase of product direction and implementation approach, but it is not presented here as a production deployment.

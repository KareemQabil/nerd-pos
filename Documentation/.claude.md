## **CRITICAL CONSTRAINTS (NON-NEGOTIABLE)**

### **1. Decimal.js is MANDATORY**

```typescript
// ✅ ALWAYS use Decimal.js for money
import Decimal from 'decimal.js';
const total = new Decimal(price).times(quantity).toDecimalPlaces(2);

// ❌ NEVER use native numbers
const total = price * quantity; // ❌ WRONG - PRECISION LOSS
```

**Why**: JavaScript floats lose precision. `0.1 + 0.2 = 0.30000000000000004`

---

### **2. Repository Pattern is REQUIRED**

```typescript
// ✅ Services ALWAYS use repositories
constructor(private repo: ProductRepository) {}

// ❌ Services NEVER use Prisma directly
constructor(private prisma: PrismaClient) {} // ❌ WRONG
```

**Why**: Separation of concerns, testability, abstraction

---

### **3. Event-Driven Communication**

```typescript
// ✅ Modules communicate via events
await this.eventBus.publish('OrderCreated', event);

// ❌ NO direct cross-module calls
await this.inventoryService.deductStock(items); // ❌ COUPLING
```

**Why**: Decoupling, modularity, LEGO architecture

---

### **4. ZATCA Hash Chain is CRITICAL**

```typescript
// MUST maintain unbroken hash chain
const currentHash = SHA256(previousHash + invoiceXML);

// Store immediately
await this.invoiceRepo.update(invoiceId, { 
  hash: currentHash,
  previousHash 
});

// If chain breaks → HALT ALL INVOICING
if (hashMismatch) {
  throw new ZATCAHashChainBrokenException(); // CRITICAL ERROR
}
```

**Why**: Saudi tax compliance. Broken chain = legal violation

---

```typescript
// All mutations must support offline sync
```

### **13. Error Handling Requirements**

**RESTRICTION**: All async code needs try-catch.

```typescript
❌ FORBIDDEN:
async function createOrder(dto: CreateOrderDto) {
  const order = await this.orderService.create(dto); // ❌ NO ERROR HANDLING
  return order;
}

✅ REQUIRED:
async function createOrder(dto: CreateOrderDto) {
  try {
    const order = await this.orderService.create(dto);
    return { success: true, data: order };
  } catch (error) {
    this.logger.error('Order creation failed', error);
    
    if (error instanceof InsufficientStockError) {
      throw new BadRequestException('Some items are out of stock');
    }
    
    throw new InternalServerErrorException('Failed to create order');
  }
}
```
